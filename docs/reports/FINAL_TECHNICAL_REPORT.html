3. Task C: 1D Steady-State Thermal FEA & $O(h^2)$ Convergence Verification

3.1 Governing Differential Equation & Boundary Conditions

The steady-state temperature distribution $T(x)$ along a 1D uniform conducting rod with volumetric heat generation $q$ is governed by the second-order ordinary differential equation: $$-k A \frac{d^2 T}{dx^2} = q A \quad \Longleftrightarrow \quad \frac{d^2 T}{dx^2} + \frac{q}{k} = 0, \quad x \in [0, L]$$ subject to prescribed Dirichlet boundary conditions: $$T(0) = T_0 = 100.0^\circ\text{C}, \quad T(L) = T_L = 20.0^\circ\text{C}$$ with assigned physical parameters: $L = 1.0\text{ m}, A = 1.0 \times 10^{-4}\text{ m}^2, k = 10.0\text{ W/(m}\cdot\text{K)}, q = 10,000.0\text{ W/m}^3$.

Integrating analytically yields the exact continuous quadratic temperature profile: $$T_\text{exact}(x) = T_0 - (T_0 - T_L)\frac{x}{L} + \frac{q}{2k} x (L - x) = 100 - 80x + 500x(1 - x) = 100 + 420x - 500x^2$$ Internal peak temperature occurs at $x^* = 0.420\text{ m}$ with $T(0.420) = 188.20^\circ\text{C} > 100^\circ\text{C}$.

3.2 Finite Element Formulation & Thomas Tridiagonal Solver

The rod is discretized into $N$ uniform 2-node linear elements of length $h = L / N$. On each element $e$, linear Lagrange shape functions $N_1(\xi) = 1 - \xi/h$ and $N_2(\xi) = \xi/h$ yield the local stiffness matrix $\mathbf{K}^e$ and load vector $\mathbf{F}^e$: $$\mathbf{K}^e = \frac{k A}{h} \begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}, \quad \mathbf{F}^e = \frac{q A h}{2} \begin{bmatrix} 1 \\ 1 \end{bmatrix}$$ Assembly across all $N$ elements results in a symmetric, positive-definite tridiagonal system: $$\mathbf{K} \mathbf{T} = \mathbf{F}$$ Applying Dirichlet boundary conditions ($T_0$ and $T_N$), the interior $(N-1) \times (N-1)$ tridiagonal system is solved directly using the Thomas algorithm ($O(N)$ computational complexity and zero memory allocation overhead).

3.3 Convergence Analysis & The Midpoint Superconvergence Discovery

In 1D linear element FEA with constant coefficients, the nodal values obtained from the Galerkin weak form coincide identically with the exact analytical solution ($T_i^\text{FEA} = T_\text{exact}(x_i)$). Evaluating errors solely at the mesh nodes would erroneously suggest zero error on all meshes.

To rigorously measure the true asymptotic truncation error, error evaluation must be performed at element midpoints: $$x_\text{mid} = x_i + \frac{h}{2}$$ Expanding $T_\text{exact}(x)$ via Taylor series around the linear interpolation: $$e(x_\text{mid}) = T_\text{exact}(x_\text{mid}) - T_\text{FEA}(x_\text{mid}) = \frac{q h^2}{8k} = 125.0 \cdot h^2$$ Empirical evaluation across $N = 10, 20, 40, 80$ elements demonstrates exact quadratic convergence ($p = 2.0000$):

6. Task F: Neural Network Simultaneous Backpropagation & Finite-Difference Validation

6.1 Mathematical Formulation

The target neural network is a single-input, single-hidden-unit feedforward architecture: $$z_1 = w x + b, \quad h = \tanh(z_1), \quad \hat{y} = v h + c, \quad J = \frac{1}{2}(\hat{y} - y)^2$$ Initial parameters: $x = 1.0, y = 2.0, w = 0.5, b = 0.0, v = 1.0, c = 0.0, \eta = 0.1$.

6.2 Analytical Gradient Derivation via Multivariate Chain Rule

Applying the multivariate calculus chain rule: $$\frac{\partial J}{\partial \hat{y}} = \hat{y} - y$$ Output layer partial derivatives: $$\frac{\partial J}{\partial v} = (\hat{y} - y) h, \quad \frac{\partial J}{\partial c} = \hat{y} - y$$ Propagating through the hyperbolic tangent activation ($\frac{d}{dz}\tanh(z) = 1 - \tanh^2(z) = 1 - h^2$): $$\delta_1 = \frac{\partial J}{\partial z_1} = (\hat{y} - y) v (1 - h^2)$$ Hidden layer partial derivatives: $$\frac{\partial J}{\partial w} = \delta_1 \cdot x, \quad \frac{\partial J}{\partial b} = \delta_1 \cdot 1.0$$

6.3 Central Finite-Difference Verification ($\epsilon = 10^{-6}$)

To mathematically verify the exact analytical expressions without reliance on third-party automatic differentiation libraries, the workbench evaluates central finite differences: $$\frac{\partial J}{\partial \theta_i} \approx \frac{J(\theta_i + \epsilon) - J(\theta_i - \epsilon)}{2\epsilon}, \quad \epsilon = 1.0 \times 10^{-6}$$ With truncation error $O(\epsilon^2) \approx 10^{-12}$, the maximum absolute error across all parameters was below $1.2 \times 10^{-10}$, exceeding the required $10^{-5}$ precision threshold:

All parameters are updated simultaneously using gradients evaluated exclusively at the original parameter values: $$\theta_i^{(k+1)} = \theta_i^{(k)} - \eta \frac{\partial J}{\partial \theta_i}\Bigg|_{\boldsymbol{\theta}^{(k)}}$$ Over 100 gradient descent steps with learning rate $\eta = 0.1$, the loss decreases monotonically from $J^{(0)} = 1.182542 \to J^{(10)} = 1.0211 \times 10^{-2} \to J^{(100)} = 1.7026 \times 10^{-20}$, predicting $\hat{y} = 2.000000$ (matching target $y = 2.0$ to machine precision).
