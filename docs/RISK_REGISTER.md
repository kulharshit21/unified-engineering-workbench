## Risk Matrix

| Risk ID | Risk Description | Probability | Impact | Detection Method | Mitigation Strategy | Owner | Current Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **R1** | No working packaged Windows executable (`Launch.exe` fails on target machine). | High | Fatal | Test execution from a separate clean directory without dev environment on PATH. | Build early minimal skeleton in Phase 1; deploy via `windeployqt` and bundle MSVC CRT DLLs locally; verify zero missing DLLs. | Packaging Lead | **Mitigated in Phase 1** |
| **R2** | Numerical solver returns analytical values instead of true assembled FEM. | Low | Fatal | Code review against `SKILL.md` / `qt-cpp-review`; inspect stiffness matrix and RHS vector values directly in test cases. | Implement explicit elemental matrix computation $K_e$, load vector $F_e$, global sparse assembly, and Thomas tridiagonal algorithm. | Numerical Lead | **Controlled by Test** |
| **R3** | Incorrect midpoint convergence calculation (e.g. evaluating only nodal errors where error is 0). | Med | High | Check convergence rate; error must decrease by ~4x when $N$ doubles ($N=10 \to 1.25, N=20 \to 0.3125, N=40 \to 0.078125, N=80 \to 0.01953125$). | Explicitly evaluate $T_\text{FE}((x_i+x_{i+1})/2)$ using shape functions $N_1=0.5, N_2=0.5$ and compare with $T_\text{exact}$. | Numerical Lead | **Controlled by Test** |
| **R4** | Parallel workers perform no real CPU work (e.g. running on UI thread or trivial sleep). | Med | High | Profile CPU thread utilization; run identical numerical solve on worker pool; verify wall-clock speedup on multi-core Ryzen. | Implement `ThreadPool` with `std::thread`, work queue, mutex/condition variables; benchmark compute-bound batch solves. | Concurrency Lead | **Controlled by Benchmark** |
| **R5** | Missing Qt platform plugin (`qwindows.dll`) or VC runtime on clean machine. | High | High | Run dependency walker / PowerShell DLL dependency script on package directory. | Use `windeployqt` with `--no-compiler-runtime` flag then explicitly vendor tested MSVC runtime DLLs (`msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`) in application directory. | Packaging Lead | **Controlled by Pipeline** |
| **R6** | Invalid ASCII STL or CSV schema crashes the application. | Med | Med | Unit test suite with malformed files, NaN/Inf, binary STL headers, empty files, missing columns. | Strict token-based parsing with error recovery, `std::from_chars` / `std::stod` with `try/catch`, actionable UI error dialogs. | C++ Core Lead | **Controlled by Test** |
| **R7** | Unsafe embedded hardware assumptions (e.g. universal JTAG connectors or conflicting voltage domains). | Med | High | Audit electrical specifications against manufacturer datasheets (Pico, Arty A7, JTAG-HS2). | Explicitly document VREF/VTREF, level shifters (3.3V vs 1.8V), directionality, and separate debug interface roles. | Embedded Lead | **Controlled by Spec** |
| **R8** | Backpropagation sequential update error (using updated parameters to compute subsequent gradients in step 1). | Med | Fatal | Step-by-step unit test asserting analytical formulas at step 1 match reference derivatives exactly before updating. | Store initial gradients in temporary variables; update all 4 parameters simultaneously using $w \gets w - \eta \frac{\partial J}{\partial w}$. | Numerical Lead | **Controlled by Test** |
| **R9** | Missing handwritten evidence (violating authentic submission gate). | Med | High | Check rubric compliance; provide derivation checklist; mark status truthfully as PENDING candidate scan. | Provide exhaustive mathematical derivation guide; create 2-page handwritten checklist; explicitly disclose candidate pending status. | Documentation Lead| **Transparently Disclosed** |
| **R10**| Invented or non-reproducible benchmark claims. | High | Fatal | Automated benchmark runner exporting raw timestamped CSVs with median calculations and system specs. | Zero-fabrication policy; commit raw benchmark output and reproducible test scripts directly to repo. | QA Lead | **Enforced by Policy** |
| **R11**| Untracked or undisclosed AI assistance. | Med | Med | Audit all generated code; maintain append-only chronological `docs/AI_USE_LOG.md`. | Record prompts, models, accepted/rejected suggestions, and candidate validation steps continuously. | Ethics Lead | **Continuously Maintained** |
| **R12**| Documentation drifting from actual source implementation. | Med | Med | Run `qt-cpp-docs` and documentation cross-reference verification script before final milestone. | Continuously update Markdown documentation after each phase; run links and path verification. | Doc Architect | **Continuously Maintained** |
| **R13**| Insufficient time remaining for packaging and verification. | High | Fatal | Implement packaging pipeline in Phase 1 rather than deferring to the end. | Smoke test `Launch.exe` and packaging scripts early and continuously. | Release Engineer| **Early Pipeline Strategy** |
